# Тоталы очков NBA

Публичная страница с последним Excel-отчётом по прематчевым тоталам очков игроков FONBET и БЕТСИТИ. Для просмотра страницы и скачивания Excel достаточно браузера. На основном листе семь столбцов. Сведения о недоступных матчах находятся в листе «Статус сбора».

## Публикация на GitHub Pages

1. Распакуйте архив. Создайте публичный репозиторий GitHub, например `nba-totals`, и загрузите в его корень содержимое архива. Включите скрытую папку `.github` с файлом `workflows/nba-report.yml`. В корне репозитория должны быть также `package.json` и `build.mjs`.
2. В репозитории откройте **Settings → Pages**. В **Build and deployment → Source** выберите **GitHub Actions**.
3. Откройте **Actions → NBA report → Run workflow**. Выберите основную ветку. После успешной публикации откройте **Settings → Pages → Visit site** и передайте клиенту этот адрес.
4. Для ручного обновления используйте **Run workflow**. На сайте ссылка «Ручной сбор для владельца» открывает эту задачу. Для запуска нужен доступ на запись в репозиторий.

Сайт и исходный код публичны. GitHub Pages и обычные GitHub Actions доступны на бесплатном тарифе для публичного репозитория. Загружайте только файлы из комплекта. Ключи доступа, токены и конфигурации других проектов для публикации не нужны.

Сбор запланирован ежедневно на **14:00 по Екатеринбургу**. Браузер и компьютер могут быть выключены. GitHub иногда начинает задачу с задержкой и может приостановить расписание публичного репозитория после 60 дней без активности. Возобновить можно на вкладке **Actions**. Если хотя бы один источник доступен, новый отчёт публикуется со статусами по матчам. Если оба источника недоступны, предыдущая версия отчёта остаётся на сайте, а ошибка появится в журнале GitHub Actions.

[Документация GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages) · [Расписание GitHub Actions](https://docs.github.com/en/actions/reference/workflows-and-actions/events-that-trigger-workflows#schedule)

## Локальная проверка

Потребуется Node.js 24. Выполните `npm ci --ignore-scripts` и `npm run build`. В папке `dist` появятся HTML, Excel и JSON. Чтобы открыть страницу локально, запустите HTTP-сервер в папке `dist`. На GitHub сборка и публикация происходят автоматически через workflow.
